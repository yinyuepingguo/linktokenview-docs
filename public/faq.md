先按问题选择入口。

## 账号与 API 密钥

### 忘记密码怎么办？

打开登录页面，点击 **忘记密码？**，使用注册邮箱重置密码。详细步骤见[注册与登录](/getting-started)。

### API 密钥是什么？

API 密钥用于访问平台服务。创建和管理方式见[创建 API 密钥](/api-keys)。

### API 密钥 丢失或疑似泄露怎么办？

立即停止使用该密钥；如果控制台支持，先禁用或删除，再创建新密钥。仍无法处理时，请[联系客服](/support)。

## 模型、费用与用量

### 当前有哪些模型？

打开[模型广场](/model-plaza)查看模型名称、模型 ID、价格单位和可用范围。

### 如何确认价格？

模型价格看[模型广场](/model-plaza)，计费方式看[定价与订阅](/pricing)。

### 余额或用量在哪里查看？

进入[余额与用量](/usage)查看余额、消费和调用记录。

## Agent 工具

### 如何判断 Agent 配置是否成功？

在目标工具中发起一次实际请求，并返回正常结果，才算配置完成。

### 工具没有对应的配置示例怎么办？

不要直接复制其他工具的配置。先查看对应的 Agent 页面；没有实测依据的字段、路径和协议不会写入帮助中心。

## 还没解决？

记录错误提示、工具版本、模型、发生时间和已尝试步骤，再[联系客服](/support)。
