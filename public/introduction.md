# 关于 LinkTokenView

LinkTokenView（联视未来）是国产大模型 API 聚合平台，面向需要调用国内主流大模型的开发者和 Agent 工具用户，提供统一、易接入的 OpenAI 兼容接口。

通过一个 API 接口，即可在平台中使用 DeepSeek、通义千问、Kimi、智谱 GLM、MiniMax、百川、讯飞星火、豆包等国产大模型。你可以根据任务需要切换模型，不必为每个模型分别适配一套接口。

## 国产大模型 API 聚合

LinkTokenView 将多个国产大模型 API 汇集到同一平台，适合用于 AI 编程、智能问答、内容生成和其他需要大模型能力的应用。具体可用模型、模型 ID 和价格，请以当前[模型广场](/model-plaza)和[定价与订阅](/pricing)页面为准。

## OpenAI 兼容接口

如果你的 Agent 工具或应用支持 OpenAI 兼容接口，通常可以通过调整接口地址、API Key 和模型名称接入 LinkTokenView。平台提供 Claude 桌面版、Codex 桌面版、Claude Code、Codex CLI 等工具的配置说明，选择对应的[Agent 工具](/agents/overview)查看操作步骤。

## Token Plan 与 Coding Plan

平台提供 Token Plan 和 Coding Plan 两类使用方式，分别适用于按 Token 使用模型 API，以及使用 AI 编程类 Agent 工具。Token 在不同模型之间通用，并按实际用量实时计费；套餐规则、价格和适用范围请以当前[定价与订阅](/pricing)页面为准。
