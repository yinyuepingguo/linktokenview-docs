# 快速开始

从注册账号到发起请求，依次完成下面五步。

## 1. 注册并登录

完成[注册与登录](/getting-started)，进入 LinkTokenView 控制台。

## 2. 创建 API 密钥

登录后进入 API 密钥页面，按页面提示创建并保存密钥。详见[创建 API 密钥](/api-keys)。

API 密钥是访问凭证。不要公开发送，也不要提交到代码仓库。

## 3. 确认余额与订阅状态

1. 进入[余额与用量](/usage)，查看当前余额和用量。
2. 进入[定价与订阅](/pricing)，查看套餐、价格、订阅入口和支付方式。
3. 如果余额、额度或订阅状态异常，按页面提示处理。

## 4. 选择并配置 Agent 工具

进入[Agent 工具接入概览](/agents/overview)，选择正在使用的工具完成配置。

如果 API 密钥页面提供配置生成功能，优先使用页面生成的内容。

## 5. 发起实际请求

配置完成后，在目标 Agent 工具中发起一次实际请求，确认返回正常结果。

如果配置保存成功但请求失败，请查看[配置失败排查](/troubleshooting/configuration)和[调用失败排查](/troubleshooting/request)。
