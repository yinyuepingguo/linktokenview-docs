# 定价与订阅

## 怎么计费

LinkTokenView 采用 **Token 计费**模式，按模型实际消耗的 Token 数量扣费。

- **计费单位**：以 $ / 1M Token（每百万 Token）为单位展示价格。
- **扣费币种**：页面展示美元 $ 符号，实际扣费以人民币结算，换算关系为 1:1。
- **计费维度**：输入 Token、输出 Token、缓存 Token 分别计价，不同模型价格不同。

模型价格请到[模型广场](/model-plaza)查看。

## 充值/订阅

有两种使用方式：

- **充值**：按需充值，增加账户余额，用多少扣多少，适合用量不固定的用户。
- **订阅**：选择包月套餐，享受固定额度，适合用量稳定的用户。

套餐、价格和订阅入口，直接在控制台查看。

## 查看余额和消费

- 登录控制台后，**仪表盘**页面顶部展示当前余额和今日消费概览。
- 进入**使用记录**可查看历史调用明细，包括请求时间、模型、Token 用量和消费金额。
- 详细操作参阅[余额与用量](/usage)。

## 注意

- 充值额度仅用于本平台 API 服务，不支持退换。
- 支付成功后系统自动发放额度，实时到账，请勿关闭支付页面，避免重复下单。
- 套餐到期后未使用的额度不累计，具体规则以控制台当前说明为准。
- 页面价格和计费说明以模型广场和控制台当前显示为准，平台保留在官方定价基础上调整折扣倍率的权利。
