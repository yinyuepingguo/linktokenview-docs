# 配置失败排查

## 先看这里

- **不知道从哪里开始**：查看 [Agent 工具接入概览](/agents/overview)。
- **还没准备好账号或密钥**：先完成[注册与登录](/getting-started)和[创建 API 密钥](/api-keys)。
- **保存后没有生效**：查看[验证配置](#验证配置)。
- **工具能启动但请求失败**：查看[调用失败排查](/troubleshooting/request)。

## 配置前

1. 记录工具名称和版本。
2. 确认已创建 API 密钥。
3. 在[模型广场](/model-plaza)确认要使用的模型。
4. 使用平台页面或工具界面提供的配置内容。

## 地址和 API 密钥

- 检查地址是否有多余空格或不可见字符。
- 确认 API 密钥已完整粘贴。
- 如果控制台提供密钥管理，检查密钥状态。

## 验证配置

- 确认修改的是工具实际使用的配置入口。
- 确认配置已保存，没有同时启用另一套冲突配置。
- 完全退出并重新打开工具；如果工具支持重新加载配置，按界面操作。
- 发起一次实际请求。

## 还是不能用

记录工具版本、配置入口、完整错误提示、复现步骤和已尝试的处理方式，再查看[调用失败排查](/troubleshooting/request)或[联系客服](/support)。

本帮助中心不提供未经当前版本实测的环境变量、配置文件、JSON/TOML 内容或 API 路由。
