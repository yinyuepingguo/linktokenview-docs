# 调用失败排查

## 先保存现场

记录以下信息：

- 使用的 Agent 工具和版本。
- 使用的模型及其在[模型广场](/model-plaza)的显示状态。
- 完整错误提示和发生时间。
- 请求失败前后余额或用量是否有变化。

截图和日志提交前，先按[联系客服](/support)中的要求处理敏感信息。

## 按错误处理

### 认证失败

确认工具使用的是预期 API 密钥，再在控制台检查密钥状态。配置文件保存成功，不代表认证已经生效。

### 地址或路由错误

检查平台地址和工具配置入口。不要自行增加或删除路径后缀。

### 模型不可用

在[模型广场](/model-plaza)确认模型是否可用，再检查工具中的模型名称或模型 ID。

### 余额或用量不足

进入[余额与用量](/usage)查看账户状态和用量记录。

### 无法判断原因

不要同时修改多个配置项。保留错误现场，记录已尝试的步骤，再参阅[配置失败排查](/troubleshooting/configuration)或[联系客服](/support)。
